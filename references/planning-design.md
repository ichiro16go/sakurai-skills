# 桜井政博のゲーム作り哲学：リファレンス

## カテゴリC: 企画・ゲーム設計 (Planning &amp; Game Design)

本書は、Claude Code等の自律成長型AIがゲーム企画の立案、仕様設計、チュートリアル構築、アイデア創出を行う際に、桜井政博のゲーム制作哲学の中核である「企画・ゲーム設計」の原則を体現するための規範リファレンスである。

---

### 1. 企画の立ち上げとアイデア創出法

- **「分解・考察・再構築」によるオリジナリティの創出**:
  - 単に面白い既存ゲームを表面的に模倣（パクリ）しても、オリジナルには及ばない [11]。
  - まず面白いと感じる要素を**「分解」**し（例: レースゲームなら「ドリフトで曲がる瞬間が楽しい」）、なぜ楽しいのかを**「考察」**し（コントロール不能な壁にぶつかるリスクと快感）、全く新しい要素と組み合わせて**「再構築」**する（ドリフトとチャージ加速を合体させ、ワンボタンにした『カービィのエアライド』） [4, 5]。
  - 『メテオス』も落ち物パズルのリスク（積み上がるブロック）を「消す」のではなく「打ち上げる」推進力に変えるという逆転の再構築から5分で基本骨子を着想した [12, 13]。
- **既存の尺度に頼らない（「〇〇のような」の禁止）**:
  - 企画書やプレゼンで「〇〇のようなゲーム」と他作を引き合いに出して説明してはならない [14]。
  - 相手が受ける印象は世代や個人のプレイ体験によって大きくズレる（「マリオのような」と言っても初代FCか、64か、オデッセイかで前提が異なる） [8]。また、類似性をアピールするくらいなら「じゃあそのオリジナルを遊べばいい」となる [8, 11]。
- **「内圧」を極限まで高めてから一気に書く**:
  - 構想段階で安易に他人に話したり、SNSで呟いてガス抜き（減圧）しない [15, 16]。頭の中で圧力を限界まで高め、その熱量を一気に企画書へぶつける [16]。

### 2. 企画書とプレゼンテーションの極意

- **企画書は「1ページ1項目・絵1枚＋テキスト2行」**:
  - 『スマブラSP』の企画書（200ページ超）のように、ページをめくるだけで漫画のようにパッパと頭に入り、読ませるのではなく「見せる」構成にする [2]。
  - 企画書に長々と能書きや企画意図、市場リサーチ、プランBを書かない [17, 18]。プレイヤーに説明できない理屈はすべて贅肉である [17, 19]。
- **プレゼンはスピード（密度とテンポ）**:
  - プレゼンは短さそのものよりも、淀みなくスピーディに進むテンポ感が命 [1]。画面の文章をただ読み上げるプレゼンは厳禁 [17]。
- **階層アウトラインによる構造化**:
  - 仕様やアイデアを整理する際は、必ずアウトライン（フォルダ階層のような構造化テキスト）を活用し、ロジックの幹と枝葉を明確に仕分ける [20]。

### 3. ゲーム導入・プレイヤー体験の設計

- **「最初の3分」で面白さを分からせる（スロースターターの罪）**:
  - プレイヤーは遊んでみて面白いかどうかを冒頭の極めて短時間で判断する [3]。長々としたプロローグ、世界観説明、操作できないムービーで待たせるゲームは大損をしている [3, 21]。
  - オープニングからいきなり山場・クライマックスに飛び込ませ（『FF7』の壱番魔晄炉襲撃、『新パルテナ』のメデューサ軍襲来のように）、まず操作の快感を味わわせる [21-24]。ストーリーや背景の解説は後からでよい [21, 23]。
- **チュートリアルは「実戦の中で能動的に学ばせる」**:
  - 無機質な練習場に閉じ込めたり、取扱説明書のような長文テキストを読ませるのは最悪 [7, 25]。
  - プレイヤーが「本編を遊んでいる」感覚のまま、自然とアクションを試さざるを得ない地形・敵配置で能動的に学習させる（『スーパーカセットビジョン』や『スーパードンキーコング3』の背景意匠、初代スマブラの『ターゲットをこわせ！』など） [7, 25]。
- **「良いお使い」の5大条件**:
  - 単なる作業・シナリオ都合のたらい回しにしないための鉄則 [26]：
    1. **報酬・見返りが適切**: 使えるアイテムや魅力的なシナリオ進展が確実にある [26]。
    2. **喜びを得るスパンが短い**: 道中の採集や戦闘でも小刻みに達成感がある [6]。
    3. **攻略の自由を与える**: 安全な遠回りか、危険な近道かを自分で選べる [6]。
    4. **結果が出たら素早く撤収させる**: 目的達成後は瞬時に帰還・報告できる（旅の帰り道は退屈なため） [6]。
    5. **展開に期待を持たせる**: 単なる雑用ではなく、背景の謎や事件への興味を引く動機づけがある [6]。

### 4. 操作感・入力・画面設計の哲学

- **ワンボタンでもゲームは成立する（4つの類型）**:
  - ボタン1つでも「連射」「タイミング」「早押し」「切り替え（長押し・離す）」の4類型があり、演出と手触りが噛み合えば奥深い遊びになる [27, 28]。多ボタン化・複雑化に逃げる前に、最小入力の快感を追求する [4]。
- **「ノーリアクション」は最大の悪**:
  - プレイヤーがボタンを押した・スティックを倒した時、ゲーム側が無反応（ノーリアクション）であることは極力避ける [29, 30]。
  - アクションが成立しない状況であっても、決定音、スキップ表示、メニューの小気味よい反応など、手応えを常に返す [29, 30]。
- **画面は「狭い窓」と自覚せよ**:
  - モニター越しに見る視界は人間の視野角（約30度）に比べ極めて狭い [27, 31]。
  - 実写の比率をそのまま持ち込んでも迫力は出ない [31]。画面内の有効面積（どこが使われているか）を意識し、標的やエフェクトをあえて誇張してレイアウトする [27]。
- **時間とフレームの感覚（秒間60フレームの基準）**:
  - ゲームの物理・レスポンスは「フレーム（1/60秒＝約16.6ms）」単位で成立する [32]。秒間60フレームでの時間感覚を数値として体に染み込ませる [32-34]。

### 5. ご褒美（動機づけ）・システム仕様・続編の鉄則

- **ご褒美と動機づけは初期設計から組み込む**:
  - 骨組みができた段階で「何をプレイヤーへのご褒美にするか」を真っ先に決める（数値上昇、装備、キャラクター解放、コレクション、実績など） [20, 35, 36]。
  - 『エアライド』のクリアチェッカーのように、目標（動機）と報酬が表裏一体となり、遊ぶこと自体に目的を与える仕組みが中毒性を生む [37, 38]。
- **スコアの見せ方を工夫する**:
  - 単なる数字の加算は現代では響かない [39]。『脳トレ』の「脳年齢」、『バーンアウト』の「被害総額」、『スマブラ』の「世界戦闘力」のように、**プレイヤーの自尊心や実感を刺激する尺度**に変換して提示する [10, 39]。
- **キャラクターの差別化は「固有仕様・専用プログラム」を惜しまない**:
  - キャラクタを立たせるには、パラメータの微差ではなく「そのキャラにしかできない特殊仕様（固有システム）」をプログラムレベルで実装し、ピーキーに尖らせる [40, 41]。
- **続編の売上は「何もしなければ約半分になる」**:
  - 続編はシステム流用により制作上有利だが、前作の満足度や鮮度に甘えると売上は激減する [9, 42]。前作を明らかに上回るパワーアップと、新規の魅力を注ぎ込まなければならない [42]。
